# Security Policy

TankFit AI is a fictional public portfolio demonstration, not a production monitoring, payment, safety, or engineering system. It must never receive real confidential information, payment data, credentials, or safety-critical instructions.

## Reporting a Vulnerability

When the public GitHub repository is available, report suspected vulnerabilities through GitHub's private vulnerability-reporting or Security Advisory feature. Do not publish exploit details, secrets, session identifiers, or personal information in a public issue.

Include:

- A concise description of the behavior
- The affected page or endpoint
- Reproduction steps using synthetic data only
- Expected and observed results
- Potential impact

## Scope

Security reports may cover the deployed TankFit AI application, session isolation, authorization, deterministic tool boundaries, public APIs, generated demo proposals, and repository configuration.

The fictional product specifications and lack of production suitability are product limitations rather than security vulnerabilities unless they permit unauthorized access, execution, disclosure, or state change.

## Response

Confirmed vulnerabilities will be prioritized by exploitability and impact. Affected functionality may be disabled while a fix is developed. No guarantee of a response time or production service level is made for this personal competition project.
