# Company Logos

Place the four generated company logo assets in this directory using the exact filenames from `docs/company-logo-prompts.md`:

- `tankroy-systems.svg`
- `airflame-fuels.svg`
- `agricuflow-cooperative.svg`
- `boreal-beverage-group.svg`

The marks are intentionally symbol-only. Company names and accessible text come from `data/companies/companies.json` and should be rendered as HTML beside the image.

Before adding an asset:

- Confirm that it is fictional and does not copy a real trademark.
- Confirm that it contains no malformed generated words, letters, numbers, watermark, or certification mark.
- Confirm that it works at both 32 px and 256 px.
- Prefer clean SVG output; use a transparent PNG only when the SVG is not reliable.
